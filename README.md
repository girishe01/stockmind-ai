# StockMind

AI-powered stock research, monitoring, analysis, and stock suggestion platform.

## Project Goals

StockMind combines:

- Fundamental analysis
- Technical analysis
- Valuation analysis
- Risk analysis
- Market and news data
- AI-assisted investment research
- Stock scoring and ranking
- Watchlists and monitoring

## Architecture

- Frontend: Next.js + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL / Supabase
- AI: OpenAI
- Market Data: External financial data APIs
